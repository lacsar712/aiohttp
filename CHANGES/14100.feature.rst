Added :py:meth:`aiohttp.ClientSession.pin_connection`, an asynchronous context manager that pins all requests with the same connection key (host, port, proxy and SSL settings) to the exact connection acquired by the first request in the scope. Concurrent requests with the same key wait for that connection instead of opening another one; requests for other keys keep using the regular pool. If the pinned connection is closed or leaves the pool (for example through a WebSocket upgrade), subsequent matching requests in the scope fail with :class:`aiohttp.ClientConnectionPinError` instead of establishing a replacement connection.
